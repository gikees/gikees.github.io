Research Interests

I am interested in representation learning and world modeling, and drawn to research built on simple, intuitive ideas. My goal is to build AI capable of understanding, reasoning, and planning with a human-like grasp of the world, which I believe has to rest on a learned representation of it. My dream is to build an agent that lives in a virtual environment, like an NPC in a game, and learns from its own experience of that world. I am curious what behavior would emerge: what would such an agent do without a given goal, would agents like it ever develop their own way of communicating?

Projects

CVJutsu GitHub

Webcam app that recognizes Naruto hand seals using MediaPipe and a RandomForest classifier. Matches seal sequences to known jutsu and triggers animated effects. Includes a built-in training pipeline for custom models. Built with Python, OpenCV, scikit-learn, and PyQt6.

SafeFlame GitHub

Real-time AI kitchen safety monitor using YOLOv8, CV heuristics, and a local LLM (Llama 3.1 via Ollama) to detect hazards and provide contextual safety advice. Features voice alerts and a live dashboard. Runs fully locally.
